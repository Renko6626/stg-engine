## 0. 这是什么项目（一页纸）

- **東方時環晷 ～ Counterfactual Alibi.**——东方 Project 二次创作，纵版弹幕射击，单自机十六夜咲夜。
- 核心玩法是三件时间工具：**停止**（时间停止，在静止的弹幕里走位）、**観測→跳躍**（看到半秒后的世界，
  跳过去）、死亡自动**遡行**（退回半秒前）。整个画面像一台仪器在记录这个世界。
- **计划商业发行**（Steam 路径确认中）。所以本次委托按商业用途签，条款见 §7。
- 本次只做**体验版**需要的三件：咲夜立绘、蕾米莉亚立绘、咲夜自机点阵。荷取及之后的角色另议。
- 图会出现在哪（决定尺寸）：

| 展示位 | 用哪张 | 显示尺寸（画面基准 1280×960） |
|---|---|---|
| 标题画面 | 咲夜全身 | 高约 820 px，占画面右侧 |
| 自机对话（后续加） | 咲夜 / 蕾米半身 | 高约 400 px，画面左右下角 |
| 弹幕区自机 | 咲夜点阵 | 64×96 px 原样显示（整数倍缩放） |

半身从全身裁切，**不另画**。

## 1. 风格圣经（两张立绘 + 点阵共用）

**母题：仪器化。** 不是赛博朋克、不是未来堆料。屏幕上的一切像刻度、准星、示波器余晖——精确、安静、冷。
角色立绘要能站在这样的画面里不突兀。

**风格：平涂赛璐璐 + 硬边描边。** 不厚涂、不渐变堆光、不柔边。理由：游戏里 64 像素的自机、几何体弹幕、
立绘三者同屏，密度必须接近，否则散架。

**三色纪律（咲夜）**：全身只有三种颜色——

| 角色 | 色 | 起手色值 | 用在 |
|---|---|---|---|
| 近黑 navy | `#141A2E` | 主体：马甲、裙、袜、靴 |
| 白 | `#F2F1EC` | 围裙、衬衫、喀秋莎 |
| 绿 | `#2FBF71` | **全身唯一高饱和色**：领带/choker、少量点缀 |

肤色与发色（银灰）是"中性色"不计入三色。**除绿以外不许出现第二种彩色**。这条纪律就是"现代感"的来源。
（色值是起手值，定稿时统一进调色板文件。）

**描边**：全部硬边、单一深色（navy 加深，不用纯黑），线宽统一（原稿 4 px，缩到显示尺寸后约 1.5–2 px）。
描边不分粗细层级，不做线条渐隐。

**明确禁止**：机械部件、LED 灯带、发光线路、科幻护目镜、大蝴蝶结、蕾丝花边、泡泡袖、渐变发光特效。

**参考方向**（附图见 §8）：高级餐厅侍者制服实拍、现代军礼服、时装摄影的 tailoring、ZeroRanger 的
极简几何画面。**不给科幻概念图。**

## 2. 咲夜 brief

**她是谁、此刻在干什么**：红魔馆女仆**长**——是管理者，不是侍女。此刻她正要出门去查一件时间的事。
姿态是"要去办事"，不是"可爱地站着"。

**保留锚点（不许动，反而要加重）**：银灰短发、两侧麻花辫、喀秋莎头饰、银质小刀、腰间怀表。
64 像素下靠这五样认人。

**改造清单（从 maid 往 butler / 侍者一侧移，做减法与剪裁，不做加法）**：

| 部位 | 原作 | 改为 |
|---|---|---|
| 袖 | 泡泡袖 | 贴身分段袖 |
| 裙 | 蓬裙 | 修身直筒 + 不对称下摆，上紧下垂，不做体积 |
| 花边 | 蕾丝 | 全删，用剪裁分割线本身当装饰 |
| 领 | 大蝴蝶结 | 立领 + 窄领带或黑色 choker（绿色在这里） |
| 马甲 | 无 | **加一件深色马甲**——把"女仆"读成"侍者"最有效的单件 |
| 围裙 | 荷叶边小围裙 | 直筒长围裙，白 |
| 腿 | — | 黑丝袜 + 硬底短靴 |

**围裙下摆的罗马数字**：印花，不发光，一圈 I–XII。这是游戏机制的视觉挂载（遡行累积时数字逐格褪色），
立绘上画完整的一圈即可。

**姿态与视线（必须照做）**：持刀手势——刀在指间，不是握拳；重心在一侧腿，另一腿放松；视线看向画面外
斜前方，不看观众。"帅来自姿态不是服装。"

**表情差分（脸部单独一层）**：① 平常——冷静、微不耐；② 冷——听到"你是不是已经死过一次了"时的那一下停顿。

## 3. 蕾米莉亚 brief

**原作造型不改造。** 只做两件事：① 套 §1 的描边规则与平涂风格；② 配色收敛（红/粉/白，饱和度压到与咲夜
同一档，不许出现荧光色）。

**她此刻在干什么**：主人正在放水考自己的女仆。表情基调：**玩味、居高临下、不凶**。

**表情差分**：① 玩味；② 收尾那句「……你刚才，是不是已经死过一次了？」时的凝视。

## 5. 咲夜自机点阵规格

**顺序**：先立绘定妆（§2 草图通过）→ 我方出一张 64×96 定妆静帧（验证服装在 64 像素下还读得出）→
你按定妆静帧画帧。**帧数委托不含设计翻译**（若你希望连翻译一起做，报价分开写）。

| 项 | 规格 |
|---|---|
| 尺寸 | **64×96 px**，每帧同尺寸，脚底锚点在 (32, 90) |
| 调色板 | 与立绘同一份（§1 三色 + 肤色 + 发色 + 描边色），点阵不超过 12 色 |
| 描边 | 1 px，单色，与立绘描边色一致；无抗锯齿 |
| 帧表 | 待机 **4** 帧（呼吸/裙摆微动）；左移 **6** 帧（含从待机到倾斜的过渡）；右移由程序镜像 **不画** |
| 不画 | 死亡（程序特效）、跳躍线框态（着色器）、低速判定点（程序） |
| 2P 换色 | 顺手出一版（三色换为：navy→深酒红、绿→金），几乎不加工 |
| 交付 | 横排 sheet（`sakuya_sheet.png`，10 帧 × 64 = 640×96）+ 每帧单独 PNG（`sakuya_idle_00.png`… `sakuya_left_05.png`） |
| 缩放 | 游戏内整数倍 + 邻近采样，所以**不要**在点阵里做半像素抗锯齿 |

## 6. 流程与确认点

| 阶段 | 你交什么 | 我方反馈 | 目的 |
|---|---|---|---|
| ① 草图 | 咲夜 2–3 个姿态草图（小图即可） | 选一个 + 姿态/剪裁意见 | **改造方向在这里定死**，后面不再动服装 |
| ② 线稿 | 定稿线稿 | 锚点/比例/描边核对 | 之后不改结构 |
| ③ 上色 | 平涂 + 表情差分 | 三色纪律核对、同屏密度测试（§8） | 交付 |
| ④ 点阵 | 定妆静帧确认后出帧 | 逐帧看动态 | 交付 |

蕾米在③之后并行。**每阶段改稿上限 2 次**，超出按小时另计——请在报价里写明小时价。

## 8. 验收标准（我方怎么看"过了"）

1. **同屏密度测试**：把咲夜点阵、一颗弹、立绘的一只眼睛放在同一张 1280×960 截图里比线宽，量级接近。
2. 缩到显示尺寸后，三色纪律与描边仍成立，没有出现第二种彩色。
3. 五个保留锚点在标题画面尺寸下一眼可辨；在 64×96 定妆静帧下至少四个可辨。
4. 表情差分只动脸部层，身体层逐像素一致。
5. 点阵 sheet 每帧脚底锚点在同一位置，来回播放不"漂"。
