# xform 表达式中的 rand

用户已在会话确认：现有 rand(n) 进入 xform 表达式，沿用绑定、at_spawn、at_effect 三阶段求值；复用 World RNG，固定顺序与短路，STEP/等待期间保持结果，重新进入操作时重新抽样。本文件记录该已确认方案，不另设审批步骤。

## 方案与边界

选择三阶段统一支持；只开放 at_effect 会留下出生随机缺口，新增随机全局变量则重复现有 rand API。普通模板操作参数在每次绑定抽样，at_spawn 每颗弹出生抽样，at_effect 每次操作进入抽样。实参仍先在调用方求值。参数和表达式按源码顺序，短路未执行部分不抽样；不合并、复制或常量折叠随机调用。

沿用 rand(n) 的 int -> int、n<=0 返回0且不消耗 RNG 的语义。表达式求值已经消耗的 RNG 不因之后参数检查失败而回滚，与普通 ECL 中先抽样再调用写口一致；原有坏参数 no-op+计数保留。World、快照与捕获布局不增加状态，8缓存/16物理槽/128指令/32栈限制不变。

## 实施选择

表达式 IR 新增一元 Rand，通过现有求值回调请求世界随机数；绑定/出生求值改用可变 WorldBody。效果求值先复制最多8个持久捕获值到栈上，避免段借用与 RNG 写入重叠，不引入新持久存储。编译白名单加入 rand，常量折叠显式排除它；其他任意sub/写操作保持禁止。

ENGINE_VER29 -> 30：新增有副作用的表达式操作与合法源程序，World布局不变；保留旧静态及无rand表达式行为。版本锚点、作者文档、转写指引和训练wheel同时同步。无卡池迁移、原作EX导入器扩展、训练、提交或推送。

## 验证

在已有编译器xform真实执行测试中覆盖三阶段/共享流、重复调用顺序与短路、STEP和WAIT_SIGNAL保持及保存恢复；扩展已有核心LOOP重入测试检查重新抽样。预期值由同seed的已有PCG32直接抽样给出，不复制随机算法、不用碰巧不相等作为正确性证据。运行相关core/compiler/harness/RL检查、fmt/clippy、表校验和本机golden对照；新wheel做编译及实际环境检查，GPU/跨平台不在本次验证范围。
