# M0-13 敌人 move_to + nearest_enemy Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** ECL 前最后的 API 补全——敌人 `move_to` 插值器（easing 飘入/飘出，杂鱼脚本第一句话）+ `nearest_enemy` 查询（homing/ECL 瞄敌基建）+ 敌人越界系统性放宽（大边界 + 纪律回收）。

**Architecture:** `mv_*` 八字段（M0-7 起躺在池里）通电：写 API `move_enemy_to` 置状态，integrate 敌人趟 `mv_active` 分支绝对插值（STEP 同款防漂移纪律）；`easing_from_id` 从 transform.rs 迁到 `math::easing` 唯一居所；敌人回收边距独立为 `ENEMY_OOB_MARGIN = 256`。上游 spec：`docs/superpowers/specs/2026-07-17-m0-13-move-to-design.md`。

**Tech Stack:** Rust 2024 / stg-core。复用 `ease`/`len_sq`/既有池句柄模式。

## Global Constraints

- **到点即停**：完成帧（`mv_t == mv_dur`）写**精确** `mv_to`（不吃插值舍入）+ `vx/vy` 清零 + `mv_active = 0`。插值期完全优先（不积分 `vx/vy`）；`invuln`/`hit_flash` tick 照常。
- **绝对插值**：`pos = from + ease(t) × (to − from)`，逐轴、每帧从 `from` 重算；`t = (mv_t << 16) / mv_dur`（i64 整数除法）；`e × d` 为 e ≤ 1.0 白名单乘法（i64 中间量，d 可达全场跨度不溢出）。
- **P4**：悬垂句柄 → `contract_viol` + `STATUS_STALE_HANDLE` no-op；`easing >= 8` → `contract_viol` + `STATUS_BAD_ARGS` no-op；`dur == 0` → 瞬移（合法退化不计数：写 `x/y` + 清 `vx/vy`，不置 `mv_active`）。进行中重下 = 覆盖重启（`mv_from` 取当前 `x/y`）。目标点不钳制场界。
- **大边界**：`ENEMY_OOB_MARGIN: i32 = 256`（world.rs 场界常量区）；仅敌人回收用它，弹/自机弹/道具维持 `OOB_MARGIN = 64`。回收主导靠纪律（M1 协程自燃——本刀只写文档 forward pointer）。
- **nearest_enemy 十条契约**（spec 定稿）：`&self` 纯查询 / 候选 = 存活且非 dying / `len_sq` 平方距离 / 严格 `<` 并列取低索引 / 空集 None 不计数 / 返回带 generation 句柄 / 无距离上限 / 纯函数 / 入参任意点。
- **TDD** 每任务红绿；合入前变异检验（T6）。commit 中文 conventional + 尾签 `Co-Authored-By: Claude Opus 4.8 (1M context) <noreply@anthropic.com>`。
- 判别值更正（spec 笔误）：大边界判别用 **y=600**（旧界 512 必死、新界 704 存活），spec 原文 y=500 在旧界也存活、无判别力。

```rust
    /// 敌人限时缓动位移（D5；杂鱼"飘入-停-飘出"的世界侧状态机，将来 ECL syscall 直通）。
    /// 语义：绝对插值、到点即停（精确终点 + 清 vx/vy）；进行中重下 = 覆盖重启；
    /// dur=0 = 瞬移（合法退化）。P4-b：悬垂/easing 越界 → no-op + 计数。目标点不钳制场界。
    pub fn move_enemy_to(&mut self, h: EnemyHandle, x: Fx, y: Fx, dur: u16, easing: u8) {
        let Some(i) = self.enemies.get(h) else {
            self.diag.contract_viol = self.diag.contract_viol.wrapping_add(1);
            self.last_status = STATUS_STALE_HANDLE;
            return;
        };
        if easing >= 8 {
            self.diag.contract_viol = self.diag.contract_viol.wrapping_add(1);
            self.last_status = STATUS_BAD_ARGS;
            return;
        }
        if dur == 0 {
            self.enemies.x[i] = x;
            self.enemies.y[i] = y;
            self.enemies.vx[i] = Fx::ZERO;
            self.enemies.vy[i] = Fx::ZERO;
            return;
        }
        self.enemies.mv_from_x[i] = self.enemies.x[i];
        self.enemies.mv_from_y[i] = self.enemies.y[i];
        self.enemies.mv_to_x[i] = x;
        self.enemies.mv_to_y[i] = y;
        self.enemies.mv_t[i] = 0;
        self.enemies.mv_dur[i] = dur;
        self.enemies.mv_easing[i] = easing;
        self.enemies.mv_active[i] = 1;
    }
```

`integrate.rs` 敌人趟——`pos += vel` 换成分支（`invuln`/`hit_flash` tick 保持在分支外照常）：

```rust
                if self.enemies.mv_active[i] != 0 {
                    // D5 插值器优先：绝对插值（每帧从 from 重算，不累积误差；e≤1.0 白名单乘法）
                    self.enemies.mv_t[i] += 1;
                    if self.enemies.mv_t[i] >= self.enemies.mv_dur[i] {
                        // 到点即停（精确终点，不吃舍入；清速防残留漂移）
                        self.enemies.x[i] = self.enemies.mv_to_x[i];
                        self.enemies.y[i] = self.enemies.mv_to_y[i];
                        self.enemies.vx[i] = Fx::ZERO;
                        self.enemies.vy[i] = Fx::ZERO;
                        self.enemies.mv_active[i] = 0;
                    } else {
                        let t = Fx::from_raw(
                            (((self.enemies.mv_t[i] as i64) << 16)
                                / self.enemies.mv_dur[i] as i64) as i32,
                        );
                        let e = crate::math::easing::ease(
                            crate::math::easing::from_id(self.enemies.mv_easing[i]),
                            t,
                        );
                        let fx = self.enemies.mv_from_x[i].raw() as i64;
                        let fy = self.enemies.mv_from_y[i].raw() as i64;
                        let dx = self.enemies.mv_to_x[i].raw() as i64 - fx;
                        let dy = self.enemies.mv_to_y[i].raw() as i64 - fy;
                        self.enemies.x[i] = Fx::from_raw((fx + ((dx * e.raw() as i64) >> 16)) as i32);
                        self.enemies.y[i] = Fx::from_raw((fy + ((dy * e.raw() as i64) >> 16)) as i32);
                    }
                } else {
                    self.enemies.x[i] = self.enemies.x[i] + self.enemies.vx[i];
                    self.enemies.y[i] = self.enemies.y[i] + self.enemies.vy[i];
                }
```

```rust
    /// 契约：纯查询零副作用；候选 = 存活且非 dying；平方距离（i64）；并列取低索引（I4）；
    /// 空集 None 不计数（合法世界状态非违约）；返回带 generation 句柄（P1）。
    pub fn nearest_enemy(&self, x: Fx, y: Fx) -> Option<EnemyHandle> {
        let mut best: Option<(usize, i64)> = None;
        let nw = self.enemies.alive.len();
        for w in 0..nw {
            let mut bits = self.enemies.alive[w];
            while bits != 0 {
                let i = w * 64 + bits.trailing_zeros() as usize;
                bits &= bits - 1;
                if self.enemies.flags[i] & crate::enemy::ENEMY_DYING != 0 {
                    continue;
                }
                let d2 = crate::math::geom::len_sq(self.enemies.x[i] - x, self.enemies.y[i] - y);
                if best.is_none_or(|(_, bd)| d2 < bd) {
                    best = Some((i, d2));
                }
            }
        }
        best.map(|(i, _)| EnemyHandle {
            index: i as u16,
            generation: self.enemies.generation[i],
        })
    }
```
