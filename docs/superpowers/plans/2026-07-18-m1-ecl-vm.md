# M1 ECL VM + 编译器 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 字节码栈机 VM + 任务协程池 + syscall 绑定 + builder DSL（临时形态，表层语言下阶段另立）——彩虹风铃环形卡跑进金向量二号，三平台对拍。

**Architecture:** 分四段落地，每段独立可验收：T1 纯地基（Task 池 + VM 核，无 step 集成，金向量逐位不变门）→ T2 协程调度 + `&EclImage` 穿线（空镜像零行为门）→ T3 syscall + appearance 表 + builder DSL（有镜像才有行为）→ T4 符卡入金向量二号（两段一文件，CI 零改动）→ T5 fuzz/变异/收尾/终审。上游 spec：`docs/superpowers/specs/2026-07-18-m1-ecl-vm-design.md`（**先整读**，拍板七项 + 承接既定全在里面）。

**Tech Stack:** Rust 2024。新模块 `stg-core/src/ecl/{task,ops,vm,image,syscall}.rs`；启用 `stg-ecl-compiler` crate。

## Global Constraints

- **编号即契约**：op 表/syscall 号表冻结纪律同 D4（十位=族号留空隙；增删改=过评审）。
- **确定性报错四联**：未知 op / pc 或跳转越界 / 栈越界（sp>32 或 csp>8 或下溢）/ 预算超限 / 除零——一律 `EVT_TASK_FAULT` 事件 + `diag.contract_viol`（或专用计数）+ 杀任务，release 绝不 panic；debug 帧内断言照 P4-c。
- **预算双层**：任务 1024 条/帧、全局 65536 条/帧，按池索引升序消耗（I4）。
- **Task 容量**：求值栈 32 / locals 64 / 调用栈 8（`CallFrame` = `ret_pc: u32` 裸字）/ 池 cap 256——全编译期常量。
- **World 新增 `tasks` 字段必入校验和 + `copy_into` 拷贝行**（快照往返判别测试钉，M0-15 同款）。
- **零行为门**（T1/T2/T3）：金向量一号流逐位不变（T1 无集成天然不变；T2 空镜像；T3 无脚本不跑）。
- git 用 mingw64 真身；cargo 卡死近零 CPU 时杀进程重试；测试跑前台。commit 中文 conventional + 尾签 `Co-Authored-By: Claude Opus 4.8 (1M context) <noreply@anthropic.com>`。
- 名字适配纪律照旧：计划代码是骨架，实况以 codebase 为准，适配记报告。

```rust
// ecl/task.rs —— 手写特例池（xform.rs 先例：存活位图即分配器，最低空位，无逐槽 generation——
// 任务句柄 = (index, birth_frame) 由调度层管；对外只 spawn/kill/iter）
pub const TASK_CAP: usize = 256;
pub const EVAL_DEPTH: usize = 32;
pub const CALL_DEPTH: usize = 8;
pub const LOCALS: usize = 64;
/// owner 三态：0=关卡（恒有效）/1=敌/2=弹；index+gen 仅 kind≠0 时有意义。
pub const OWNER_STAGE: u8 = 0;
pub const OWNER_ENEMY: u8 = 1;
pub const OWNER_BULLET: u8 = 2;

#[repr(C)]
#[derive(Clone, Copy, crate::checksum::Checksum)]
pub struct Task {
    pub script: u16,        // EclImage.subs 入口索引
    pub pc: u32,
    pub wait: u16,
    pub born_frame: u32,    // == 当前帧则本帧跳过（次帧首跑）
    pub owner_kind: u8,
    pub owner_index: u16,
    pub owner_gen: u16,
    pub parent: u16,        // 任务池索引 + 1；0 = 无父（仅 kill_children 遍历用）
    pub sp: u8,
    pub csp: u8,
    pub stack: [i32; EVAL_DEPTH],
    pub calls: [u32; CALL_DEPTH],
    pub locals: [i32; LOCALS],
}

pub struct TaskPool { pub(crate) slots: [Task; TASK_CAP], pub(crate) alive: [u64; 4] }
impl TaskPool {
    pub(crate) fn spawn(&mut self, script: u16, owner: (u8, u16, u16), parent: u16, frame: u32) -> Option<u16>;
    pub(crate) fn kill(&mut self, i: usize);
    pub(crate) fn is_alive(&self, i: usize) -> bool;
    pub fn iter_alive(&self) -> impl Iterator<Item = usize> + '_;
    pub(crate) fn copy_into(&self, dst: &mut TaskPool);  // Checksum 手写或 derive——slots 全量入哈希（P6）
}
```

```rust
// ecl/ops.rs —— 编号即契约（spec 指令集 v1 全表）+ 元数表
pub const OP_END: u8 = 0;  pub const OP_WAIT: u8 = 1;  pub const OP_JMP: u8 = 2;
pub const OP_JZ: u8 = 3;   pub const OP_CALL: u8 = 4;  pub const OP_RET: u8 = 5;
pub const OP_PUSHI: u8 = 10; pub const OP_PUSHL: u8 = 11; pub const OP_POPL: u8 = 12;
pub const OP_DUP: u8 = 13; pub const OP_POP: u8 = 14;
pub const OP_ADD: u8 = 20; /* SUB21 MUL22 DIV23 MOD24 NEG25 */
pub const OP_MULF: u8 = 30; /* DIVF31 SINB32 COSB33 */
pub const OP_EQ: u8 = 40; /* NE41 LT42 LE43 GT44 GE45 */
pub const OP_SPAWN: u8 = 50; pub const OP_KILL_SELF: u8 = 51; pub const OP_KILL_CHILDREN: u8 = 52;
pub const OP_SYS: u8 = 60;
pub const ARITY: [u8; 256] = { /* JMP/JZ/CALL=1（目标字）PUSHI/PUSHL/POPL=1 SPAWN=1（script id）
                                  SYS=1（syscall 号）其余 0；未实现 op 元数 0 */ };
pub fn op_implemented(op: u8) -> bool;
```

```rust
// ecl/vm.rs —— 单任务解释核（T1 版不含 SPAWN/SYS 的实际派发——踩到返回 Fault 由 T2/T3 接管；
// 但解码与预算完整）
pub(crate) enum Exec { Yield, End, Fault(u8) /* fault 码：0 坏op 1 pc越界 2 栈溢 3 预算尽 4 除零 5 调用深 */ }
pub(crate) struct VmCtx<'a> { pub code: &'a [u32], pub budget: &'a mut u32 /* 全局余额，任务预算内部另计 */ }
pub(crate) fn exec(task: &mut Task, ctx: &mut VmCtx) -> Exec;
// 循环：预算门（任务 1024 + 全局）→ 取头字（pc 越界→Fault(1)）→ op 低 8 位 → op_implemented?
// → 按 ARITY 取操作数字 → 语义分派 → WAIT 写 wait 并 Yield / END → End。
// 算术：MULF = ((a as i64 * b as i64) >> 16) as i32；DIV/MOD/DIVF 除零 Fault(4)；
// SINB/COSB：栈顶 BAM（低 16 位）→ math::trig 查表值（Q16.16）。
```
