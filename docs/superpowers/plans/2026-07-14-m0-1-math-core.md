# M0-1: 定点数学核 (D1) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 `stg-core` 落地一套跨平台 bit 级确定的定点数学核——`Fx`(Q16.16) / `Angle`(BAM u16) 强类型、算术、`sin/cos/atan2/isqrt`、easing 曲线——全部走"commit 字节 + CI 再生成断言"的烘焙表纪律。

**Architecture:** 纯整数、无状态纯函数库，住 `stg-core/src/math/`。超越函数（sin/cos/easing/atan 常数）**绝不在构建期用浮点现算**：由断层线【以上】的 `stg-harness bake-tables`（用 f64）生成【原始小端字节】commit 进 `crates/stg-core/src/math/tables/*.bin`，`stg-core` 用 `include_bytes!` + `const fn` 解码为编译期数组消费。`stg-harness verify-tables` 在 CI 里重新生成并断言与 commit 字节逐位相同。`atan2` 走整数 CORDIC（钉死 16 轮），`isqrt` 用 std（结果数学唯一，天然确定）。

**Tech Stack:** Rust 1.92.0（edition 2024），`stg-core`（零外部依赖），`stg-harness`（可用 f64，`f64::round_ties_even`）。

## Global Constraints

逐条来自 `design_doc.md` §2 / `stg-world-design.md` D1、D11 与 `CLAUDE.md`，每个任务都隐含遵守：

- **I1 数值**：`stg-core` 唯一标量是 `Fx = Q16.16(i32)`；`f32/f64` **不得**出现在 `stg-core` 任何源文件。
- **I2 角度**：`Angle = BAM(u16)`，一圈 = 65536，天然模回绕；三角函数一律查表。
- **`Fx::mul`**：`((a as i64 * b as i64) >> 16) as i32`——算术右移（向负无穷截断）。
- **`Fx::div`**：`(((a as i64) << 16) / b as i64) as i32`——向零截断（Rust 整数除法）。
- **溢出纪律**：debug `overflow-checks = true`（`+/-` 溢出即 panic）；`mul` 的 `i64→i32` 收窄用 `debug_assert!` 守范围。release wrapping。
- **`Angle` 运算一律用 `wrapping_add/wrapping_sub`**（绝不用 `+/-`，否则 debug overflow-checks 会在正常回绕时 panic）。
- **烘焙表纪律（§2.1）**：生成一次 → commit 原始字节 → `include_bytes!` 嵌入 → CI 再生成断言逐位相同；取整 **round-half-to-even**（`f64::round_ties_even`）。
- **字节序**：多字节整数一律**小端**（x86_64/aarch64 全小端，与 `checksum.rs` 契约一致）。
- **依赖防火墙**：`stg-core/Cargo.toml` 不得新增 `rand/getrandom/*time*/libm/godot`。
- **`.gitattributes` 已保证 `*.bin` 走 binary**（无 EOL 转换）——commit 的表字节跨平台逐位稳定。
- **提交纪律**：小步频繁提交；每个 commit 结尾附 `Co-Authored-By: Claude Opus 4.8 (1M context) <noreply@anthropic.com>`。

//! `Fx` —— Q16.16 定点标量（I1）。16 位整数 + 16 位小数，范围 ±32768，精度 ≈ 1.5e-5。

/// Q16.16 定点数。`repr(transparent)` ⇒ 与裸 `i32` 同布局（SoA / memcpy 快照 / 零拷贝无感）。
#[repr(transparent)]
#[derive(Clone, Copy, PartialEq, Eq, PartialOrd, Ord, Hash, Debug)]
pub struct Fx(pub i32);

impl Fx {
    pub const ZERO: Fx = Fx(0);
    pub const ONE: Fx = Fx(1 << 16);

    /// 整数 → 定点（`n * 65536`）。
    #[inline]
    pub const fn from_int(n: i32) -> Fx {
        Fx(n << 16)
    }

    /// 定点 → 整数，向负无穷取整（算术右移）。
    #[inline]
    pub const fn to_int_floor(self) -> i32 {
        self.0 >> 16
    }

    /// 取原始 i32 位。
    #[inline]
    pub const fn raw(self) -> i32 {
        self.0
    }

    /// 从原始 i32 位构造。
    #[inline]
    pub const fn from_raw(bits: i32) -> Fx {
        Fx(bits)
    }

    /// 定点乘：i64 中间量 + 算术右移（向负无穷截断）。
    #[inline]
    pub fn mul(self, rhs: Fx) -> Fx {
        let p = (self.0 as i64 * rhs.0 as i64) >> 16;
        debug_assert!(
            p >= i32::MIN as i64 && p <= i32::MAX as i64,
            "Fx::mul overflow"
        );
        Fx(p as i32)
    }

    /// 定点除：被除数左移 16 再除，向零截断。
    #[inline]
    pub fn div(self, rhs: Fx) -> Fx {
        let q = ((self.0 as i64) << 16) / rhs.0 as i64;
        debug_assert!(
            q >= i32::MIN as i64 && q <= i32::MAX as i64,
            "Fx::div overflow"
        );
        Fx(q as i32)
    }
}

impl core::ops::Add for Fx {
    type Output = Fx;
    #[inline]
    fn add(self, rhs: Fx) -> Fx {
        Fx(self.0 + rhs.0)
    }
}
impl core::ops::Sub for Fx {
    type Output = Fx;
    #[inline]
    fn sub(self, rhs: Fx) -> Fx {
        Fx(self.0 - rhs.0)
    }
}
impl core::ops::Neg for Fx {
    type Output = Fx;
    #[inline]
    fn neg(self) -> Fx {
        Fx(-self.0)
    }
}

#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn constants_and_conversion() {
        assert_eq!(Fx::ONE.0, 65536);
        assert_eq!(Fx::from_int(3).0, 3 * 65536);
        assert_eq!(Fx::from_int(-2).0, -2 * 65536);
        assert_eq!(Fx::from_int(7).to_int_floor(), 7);
        // 向负无穷取整：-0.5 → -1
        assert_eq!(Fx(-(1 << 15)).to_int_floor(), -1);
    }

    #[test]
    fn add_sub_neg() {
        assert_eq!((Fx::ONE + Fx::ONE).0, 2 * 65536);
        assert_eq!((Fx::from_int(5) - Fx::from_int(8)).0, -3 * 65536);
        assert_eq!((-Fx::ONE).0, -65536);
    }

    #[test]
    fn mul_basic() {
        // 2.0 * 3.0 = 6.0
        assert_eq!(Fx::from_int(2).mul(Fx::from_int(3)), Fx::from_int(6));
        // 0.5 * 0.5 = 0.25
        let half = Fx(1 << 15);
        assert_eq!(half.mul(half), Fx(1 << 14));
        // 乘 ONE 是恒等
        assert_eq!(Fx(12345).mul(Fx::ONE), Fx(12345));
    }

    #[test]
    fn mul_truncates_toward_neg_inf() {
        // (-1 raw) * ONE>>?：验证算术右移向负无穷。(-1) 表示 -1/65536。
        // (-1) * (1.0) = -1 raw（乘 ONE 恒等，覆盖符号路径）
        assert_eq!(Fx(-1).mul(Fx::ONE), Fx(-1));
        // 极小负数 * 极小正数 → 结果 >>16 向 -inf
        // (1 raw) * (1 raw) = (1*1)>>16 = 0
        assert_eq!(Fx(1).mul(Fx(1)), Fx(0));
        // (-1 raw) * (1 raw) = (-1)>>16 = -1（算术右移向 -inf，不是 0）
        assert_eq!(Fx(-1).mul(Fx(1)), Fx(-1));
    }

    #[test]
    fn div_basic() {
        // 6.0 / 3.0 = 2.0
        assert_eq!(Fx::from_int(6).div(Fx::from_int(3)), Fx::from_int(2));
        // 1.0 / 2.0 = 0.5
        assert_eq!(Fx::ONE.div(Fx::from_int(2)), Fx(1 << 15));
        // 向零截断：(-7 raw) / (2.0) = -3 raw（-3.5 → -3 向零）
        assert_eq!(Fx(-7).div(Fx::from_int(2)), Fx(-3));
    }
}

//! `Angle` —— BAM（Binary Angular Measurement）u16，一圈 = 65536（I2）。
//! u16 天然模 65536 回绕；**一切加减用 `wrapping_*`**，绝不用会在 debug 触发 overflow-checks 的 `+/-`。

/// BAM 角度。`repr(transparent)` ⇒ 与裸 `u16` 同布局。
#[repr(transparent)]
#[derive(Clone, Copy, PartialEq, Eq, PartialOrd, Ord, Hash, Debug)]
pub struct Angle(pub u16);

impl Angle {
    pub const ZERO: Angle = Angle(0);
    pub const QUARTER: Angle = Angle(16384); // π/2
    pub const HALF: Angle = Angle(32768); // π
    pub const THREE_QUARTER: Angle = Angle(49152); // 3π/2

    /// 回绕加。
    #[inline]
    pub const fn add(self, rhs: Angle) -> Angle {
        Angle(self.0.wrapping_add(rhs.0))
    }

    /// 回绕减。
    #[inline]
    pub const fn sub(self, rhs: Angle) -> Angle {
        Angle(self.0.wrapping_sub(rhs.0))
    }

    /// 施加有符号增量（`ang_vel: i16`，BAM/帧）。负增量即反向回绕。
    #[inline]
    pub const fn add_delta(self, delta: i16) -> Angle {
        Angle(self.0.wrapping_add(delta as u16))
    }

    #[inline]
    pub const fn raw(self) -> u16 {
        self.0
    }
}

impl core::ops::Add for Angle {
    type Output = Angle;
    #[inline]
    fn add(self, rhs: Angle) -> Angle {
        Angle::add(self, rhs)
    }
}
impl core::ops::Sub for Angle {
    type Output = Angle;
    #[inline]
    fn sub(self, rhs: Angle) -> Angle {
        Angle::sub(self, rhs)
    }
}

#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn wraps_full_circle() {
        // 3π/2 + π/2 = 2π ≡ 0
        assert_eq!(Angle::THREE_QUARTER.add(Angle::QUARTER), Angle::ZERO);
        // 0 - π/2 = 3π/2（回绕，不 panic）
        assert_eq!(Angle::ZERO.sub(Angle::QUARTER), Angle::THREE_QUARTER);
    }

    #[test]
    fn add_delta_signed() {
        // 从 0 施加 -1 → 65535
        assert_eq!(Angle::ZERO.add_delta(-1), Angle(65535));
        // 从 QUARTER 施加 +100
        assert_eq!(Angle::QUARTER.add_delta(100), Angle(16484));
        // 从 0 施加 i16::MIN(-32768) → 32768（回绕到 HALF）
        assert_eq!(Angle::ZERO.add_delta(i16::MIN), Angle::HALF);
    }

    #[test]
    fn ops_sugar() {
        assert_eq!(Angle::QUARTER + Angle::QUARTER, Angle::HALF);
        assert_eq!(Angle::HALF - Angle::QUARTER, Angle::QUARTER);
    }
}

//! `const fn` 字节→数组解码器——烘焙表机制共享。表以原始【小端】字节 commit，
//! 编译期解码为定长数组（零运行时开销）。字节序契约见 CLAUDE.md / checksum.rs。

/// 把 `4*N` 字节小端解码为 `[i32; N]`。字节数不匹配则编译期 panic（const eval）。
pub const fn decode_i32<const N: usize>(bytes: &[u8]) -> [i32; N] {
    assert!(bytes.len() == N * 4, "decode_i32: 字节数与 N 不符");
    let mut out = [0i32; N];
    let mut i = 0;
    while i < N {
        let b = i * 4;
        out[i] = i32::from_le_bytes([bytes[b], bytes[b + 1], bytes[b + 2], bytes[b + 3]]);
        i += 1;
    }
    out
}

/// 把 `2*N` 字节小端解码为 `[u16; N]`。
pub const fn decode_u16<const N: usize>(bytes: &[u8]) -> [u16; N] {
    assert!(bytes.len() == N * 2, "decode_u16: 字节数与 N 不符");
    let mut out = [0u16; N];
    let mut i = 0;
    while i < N {
        let b = i * 2;
        out[i] = u16::from_le_bytes([bytes[b], bytes[b + 1]]);
        i += 1;
    }
    out
}

/// sin 四分之一波：`[i32; 16385]`，`v[i] = round_ties_even(sin(i·(π/2)/16384)·65536)`。
pub fn gen_sin_quarter() -> Vec<u8> {
    let mut out = Vec::with_capacity(16385 * 4);
    for i in 0..=16384i64 {
        let theta = (i as f64) * (PI / 2.0) / 16384.0;

        out.extend_from_slice(&v.to_le_bytes());
    }
    out

    for (name, gen) in registry() {
        let bytes = gen();
        std::fs::write(table_path(name), &bytes)?;
        eprintln!("baked {name} ({} bytes)", bytes.len());
    }
    Ok(())
}

pub fn verify_all() -> Result<(), String> {
    for (name, gen) in registry() {
        let expected = gen();
        let path = table_path(name);

            .map_err(|e| format!("读取 {} 失败: {e}", path.display()))?;

            return Err(format!(
                "{name} 与 commit 字节不一致（生成 {} 字节 vs commit {} 字节）",
                expected.len(),
                actual.len()
            ));
        }
        eprintln!("verified {name} ({} bytes)", expected.len());
    }
    Ok(())
}

    QuadIn = 1,
    QuadOut = 2,
    QuadInOut = 3,
    CubicIn = 4,

    CubicInOut = 6,
    Smoothstep = 7,

/// `EASING[row*257 + col]`，col ∈ 0..=256 对应归一化 t，值为 Q16.16 [0,1]。

/// 缓动：`t` 归一化 Q16.16（钳制到 [0,1]），返回缓动后的归一化值。相邻档线性插值。
pub fn ease(curve: Easing, t: Fx) -> Fx {

    let frac = scaled & 0xFFFF; // [0,65536)
    let v = a + (((b - a) * frac) >> 16);
    Fx::from_raw(v as i32)
}

/// 8 条 easing 曲线，每条 257 项 Q16.16 归一化 [0,1]。
pub fn gen_easing() -> Vec<u8> {
    // 曲线定义（f64，t ∈ [0,1]）——顺序必须与 Easing 枚举一致。
    let curves: [fn(f64) -> f64; 8] = [
        |t| t,                                                   // Linear
        |t| t * t,                                               // QuadIn
        |t| 1.0 - (1.0 - t) * (1.0 - t),                         // QuadOut
        |t| if t < 0.5 { 2.0 * t * t } else { 1.0 - (-2.0 * t + 2.0).powi(2) / 2.0 }, // QuadInOut
        |t| t * t * t,                                           // CubicIn
        |t| 1.0 - (1.0 - t).powi(3),                             // CubicOut
        |t| if t < 0.5 { 4.0 * t * t * t } else { 1.0 - (-2.0 * t + 2.0).powi(3) / 2.0 }, // CubicInOut
        |t| t * t * (3.0 - 2.0 * t),                             // Smoothstep
    ];
    let mut out = Vec::with_capacity(8 * 257 * 4);
    for f in curves {
        for i in 0..=256i64 {
            let t = (i as f64) / 256.0;
            let v = (f(t) * 65536.0).round_ties_even() as i32;
            out.extend_from_slice(&v.to_le_bytes());
        }
    }
    out
}

//! `atan2` —— 整数 CORDIC 向量模式，迭代次数**钉死 16 轮**（次数是契约，改 = bump engine_ver）。
//! 纯整数移位加减，天然确定；免二维查表。角度常数表 `atan(2^-i)`（BAM）由 harness 生成并 commit。

use crate::math::codec::decode_u16;
use crate::math::{Angle, Fx};

const ITERS: usize = 16;

/// `ATAN_BAM[i] = round_ties_even(atan(2^-i) / (2π) · 65536)`。
const ATAN_BAM: [u16; ITERS] = decode_u16(include_bytes!("tables/atan_cordic.bin"));

/// `atan2(y, x) -> Angle`（BAM）。定义域含 (0,0) → 返回 0（约定）。
pub fn atan2(y: Fx, x: Fx) -> Angle {
    let mut x = x.raw() as i64;
    let mut y = y.raw() as i64;
    if x == 0 && y == 0 {
        return Angle::ZERO;
    }
    // 象限预旋到 x>0 半平面，累加已旋角度（BAM，i32 中间量）。
    let mut angle: i32 = 0;
    if x < 0 {
        // 旋 ±π（HALF）到右半平面：绕原点转 180°。
        x = -x;
        y = -y;
        angle = angle.wrapping_add(Angle::HALF.raw() as i32);
    }
    // 现在 x>0。CORDIC 向量模式：把 y 逼近 0，累加/累减各级 atan(2^-i)。
    for i in 0..ITERS {
        let da = ATAN_BAM[i] as i32;
        if y > 0 {
            let nx = x + (y >> i);
            let ny = y - (x >> i);
            x = nx;
            y = ny;
            angle = angle.wrapping_add(da);
        } else {
            let nx = x - (y >> i);
            let ny = y + (x >> i);
            x = nx;
            y = ny;
            angle = angle.wrapping_sub(da);
        }
    }
    Angle(angle as u16)
}

    }

    #[test]
    fn roundtrip_with_sincos() {
        use crate::math::sincos;
        // 从若干角度取单位向量，atan2 回来应接近原角
        for &a in &[1000u16, 9000, 20000, 33000, 50000] {
            let (s, c) = sincos(Angle(a));
            let back = atan2(s, c);
            let d = (back.raw() as i32 - a as i32).rem_euclid(65536);
            let d = d.min(65536 - d);
            assert!(d <= 12, "a={a} back={} dist={d}", back.raw());
        }
    }
}

/// CORDIC 角度常数：`atan(2^-i)`（弧度）转 BAM，16 项。
pub fn gen_atan_cordic() -> Vec<u8> {
    let mut out = Vec::with_capacity(16 * 2);
    for i in 0..16i32 {
        let rad = (2f64.powi(-i)).atan();
        let bam = (rad / (2.0 * PI) * 65536.0).round_ties_even() as i64;
        out.extend_from_slice(&(bam as u16).to_le_bytes());
    }
    out
}

## 执行修订（as-built，实现时发现，后续 M0-x 计划请预先规避）

1. **`Fx` 乘除用 `Mul`/`Div` trait，非 inherent `.mul()`/`.div()`**：clippy `should_implement_trait` 拦下 inherent 命名；trait 实现更贴合 D1"重载 mul"，调用改 `a * b` / `a / b`（含 trig 勾股测试）。
2. **edition 2024 保留字 `gen`**：harness `for (name, gen)` 编译报错，变量改名 `generate`。写标识符时避开 `gen`。
3. **大烘焙表用 `static` 非 `const`**：clippy `large_const_arrays`（64KB 的 `SIN_QUARTER`、8KB 的 `EASING`）——`static` 单实例，避免每用点复制。小表 `ATAN_BAM`(32B) 仍 `const`。
4. **harness 类型别名消 `type_complexity`**：`type TableGen = fn() -> Vec<u8>;`、`type Curve = fn(f64) -> f64;`。
5. **CORDIC 循环用 `.iter().enumerate()`**：clippy `needless_range_loop`（`i` 既索引 `ATAN_BAM` 又作移位量，仍被判可迭代）。
6. **bootstrap 顺序（关键）**：harness 依赖 core，若先给 core 加 `include_bytes!` 而 `.bin` 未生成 → core 编译失败 → harness 也编不了 → 无法 bake 生成 `.bin`（死锁）。**正确序：先写 harness 生成器 → `bake-tables` 生成 `.bin` → 再给 core 接 `include_bytes!`。**
7. **CI 观察**：`verify-tables` 在三平台（win/linux-x86_64/linux-aarch64）跑，实测三家 f64 `sin`/`atan` + `round_ties_even` 对本批采样点产出逐字节一致的表——§2.1 担心的 libm 分歧未发生；该三平台校验遂兼作"f64 分歧金丝雀"，保留。
8. **工具 sidecar**：`.gitignore` 增 `*.tags`（某后台工具在 `.bin` 旁生成的空 `[]` sidecar）。
9. **linear 亦烘入表**：D1 原设想"linear 直算不烘"，实现改为**统一 8 条全烘**（identity 为第 0 行）——`ease()` 零特例、表结构统一，代价 +1KB、精确无损。D1 该处已同步；各曲线公式/手感落在 `Easing` 变体注释。
