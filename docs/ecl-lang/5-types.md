# 5 · 三型、字面量与语句

> 这一篇是语言本身的完整规矩：三种标量类型、字面量后缀、运算矩阵、cast 白名单、语句表。
> 前四篇你已经用过它们了——`2.0fx`、`90deg`、`_ = fire(...)`、`for i in 0..5`——这一篇
> 解释为什么必须那样写。撞过一次"期待 Angle，实际 Int"再读，挂靠点最结实。

## 类型：`int` / `fx` / `angle`——三型，无隐式转换

这一格是任何花括号语言的经验都救不了的：三种标量互不隐式转换，字面量靠**后缀**分型。

- **裸整数 = `int`。**
- **`1.5fx` / `1.5px` = `fx`**（Q16.16，精确十进制折叠，round-half-even）。裸 `1.5` 无后缀是
  **词法错误**（"浮点数字面量缺少单位后缀"）——不会被当成 int 静默截断。
- **`90deg` = `angle`**（BAM），`16384bam` = `angle` 原值。裸 `90` 是 `int`，放在角度位上报
  "期待 Angle，实际 Int"。

运算矩阵（非法组合 = 编译错误并提示 cast）：

| 组合 | 结果 |
|---|---|
| `int ⊕ int` | `int` |
| `fx ± fx` · `fx * int`（普通乘）· `fx * fx`（定点乘）· `fx / int` · `fx / fx`（定点除） | `fx` |
| `int / fx` | **非法**——方向性陷阱，整除会错位 65536 倍 |
| `angle ± angle` | `angle`（回绕） |
| `angle *` · `angle /` | **一律非法** |
| 同型比较 | `int`（0/1） |
| `&&` · `\|\|` · `!` | 仅 `int`，短路求值 |

cast 白名单只有四条，其余组合拒绝：

- `int as fx`（×65536）
- `fx as int`（÷65536，**向零截断**——与引擎内算术右移对负数不同，`-1.5fx as int == -1`）
- `int as angle` / `angle as int`（**位穿透**，不是"转成度"：`90 as angle` ≠ 90°）

定点数本身的坑（`Q16.16 × Q16.16` 什么时候溢出、什么时候该留 Q32.32 累加器、角度回绕）
见 [`fixed-point-corners.md`](../fixed-point-corners.md)——那份是引擎侧口径，脚本里能撞到的
是同一套算术。

## 语句

`var name: type = expr;` · 赋值 · `if c {} else {}` · `while c {}` · `loop {}` ·
`for i in a..b {}`（半开区间，`i` 为 `int`）· `break` / `continue` · `wait(n);` ·
`spawn f(args);` · `return;` · `wait_spell();`（符卡等待语法糖，见
[6 · 符卡与整局编排](6-spell-and-stage.md)）· 表达式语句。

表达式语句有两条对称的规矩，都是编译期挡住的：

- 有返回值的 builtin 不作表达式用时**必须 `_ = ` 显式弃值**（`_ = fire(...);`）。不丢弃是
  编译错误"返回值未消费"——这是"忘 POP 远处爆栈"这把足枪的语言层灭除。
- **void builtin 只能裸语句**，前面加 `_ = ` 反而是编译错误"无返回值，无值可丢弃"。`_ =`
  只对有返回值的调用有意义。
