# 8 · 报错、静默降级与已知限制

> 这一篇讲**出错的时候会发生什么**：编译错误长什么样、运行期哪些错误会响亮地杀任务、
> 哪些只是静默地什么都不做，以及 v1 明确不支持的东西。读之前该已经写过一段脚本
> ——这一篇是排错时回来查的。

## 编译期：错误格式

错误：`文件:行:列: 说明` + 源行摘录 + `^` 定位；一个错误不吞后续（恢复到语句边界）。

## debug 循环（改代码 → check → 再改）

写/改 `.ecl` 脚本的最短反馈环，人 / coding agent / CI 共用：

1. 改 `.ecl` 源码；
2. `cargo run -p stg-harness -- check <file.ecl>`——**通过** = 打印 `OK`、退出码 0；
   **不通过** = 逐条 `文件:行:列: 说明` + 源行摘录 + `^` 定位打到 stderr、退出码 1
   （文件不存在或不带参数是第三路，退出码 2）；回第 1 步照错误位置改，不通过就不必往下走。
3. `check` 只证明"编译通过"，**不证明"跑起来对"**——真要把脚本接进金向量/查看器/游戏前，
   先跑一遍 `cargo test --workspace` 保证没有引入既有回归（含编译器自身的确定性测试），
   再上场跑 `golden`/`serve`。

## 运行期：什么会 Fault、什么只是静默降级

编译过了不等于跑得对。运行期出岔分两类，分界是引擎的 P4 三铁律：**调用方违约 → 确定性安全
结果**（整条 no-op + 违约计数，脚本继续跑）、**资源耗尽 → 确定性降级**（短路 + 池满计数），
而 **Fault 是"这条任务写错了"的响亮失败**（任务当场被杀 + 发 `EVT_TASK_FAULT`）。

**注意一类不再算"运行期"的问题**（引擎第二刀 §4，2026-09-24 起）：坏 op、非法跳转目标、
`call`/`spawn` 指向的目标 kind 不对、局部变量下标越界、坏 syscall 号——这些字节码层面
**静态就能判**的问题，`.ecl` 编译产出镜像时（`try_from_parts`）已经在加载闸挡下、当编译
错误报出来，走不到这一节说的"运行期 Fault"。正常写 `.ecl` 表层语言的作者不会亲手拼出这类
坏字节码（`call`/`spawn` 目标 kind 不对是仅剩会撞见的一条，见各篇"目标须为…"的用法说明），
这里点一句是给读字节码层（`ecl-ops.md`）或手搭 `EclImage` 的开发者备查。

下面这张索引把散在各篇的判定汇总一处，细则在各自那一节里。

**会 Fault（任务当场死）**

| 情形 | 细则在 |
|---|---|
| owner 不是敌的任务调运动动词 / `die` / `drop_*` / `spell_begin` | [3 · 敌人](3-enemy.md) |
| owner 不是弹的任务调弹 setter 族（`set_speed`/`turn`/…） | [4 · 弹](4-bullets.md) |
| `fire`/`batch`/`sh_fire` 的弹型+色号越界或落在图集空格（两参全设才查） | [4 · 弹](4-bullets.md) |
| `sh_xform` 区间越界、`sh_task` 的 sub 号不在册或不是零参 `async sub` | [4 · 弹](4-bullets.md) |
| 单任务指令预算烧穿（`loop {}` / `loop { wait(0); }`）= `FAULT_BUDGET` | [2 · 任务与时间](2-tasks.md) |

**静默降级（脚本照跑，画面上什么都没有——最难查的一类）**

| 情形 | 处置 | 细则在 |
|---|---|---|
| `wait(n)` 的 `n` 超 `u16` | 截低 16 位，**无诊断** | [2 · 任务与时间](2-tasks.md) |
| `easing` 曲线号越界 | 整条运动调用 no-op + 违约计数 | [3 · 敌人](3-enemy.md) |
| `drop_add` 的 `type` 越界 | no-op + 违约计数；`n` 钳 `[0,255]` 饱和 | [3 · 敌人](3-enemy.md) |
| `enemy_x`/`enemy_y` 拿到死号 | 返 `0`（不是哨兵，先 `enemy_alive` 探活） | [3 · 敌人](3-enemy.md) |
| 发射器槽号越界、`n_angle`/`n_speed` 为 0 或积超弹池 | 整条 `sh_fire` no-op + 违约计数 | [4 · 弹](4-bullets.md) |
| 弹池 / xform 段池满 | 从满的那颗起短路，已发的留着，计 `pool_full` | [4 · 弹](4-bullets.md) |
| 任务池满（`sh_task` / `fire` 的 task 参） | 弹保留、任务丢 | [4 · 弹](4-bullets.md) |
| `set_shape`/`set_color` 部分设撞图集空格 | 弹变透明继续飞，编译期运行期都不拦 | [4 · 弹](4-bullets.md) |
| 脚本写 `globals` 系统段（槽 < 16） | no-op + `contract_viol`，不 Fault | [6 · 符卡与整局编排](6-spell-and-stage.md) |
| `add_lives`/`add_bombs`/`add_power`/`add_score` 越界 | 钳位/饱和，**是正常语义**、不计违约 | [6 · 符卡与整局编排](6-spell-and-stage.md) |
| `clear_bullets` 时作用区池满 | 这一帧的清弹静默失效 | [6 · 符卡与整局编排](6-spell-and-stage.md) |
| 一次消掉的弹多于道具池余量 | 弹照消，**多出的星星生不出来**（逐颗计 `pool_full`）——已知设计边界 | [6 · 符卡与整局编排](6-spell-and-stage.md) |
| `emit_req` 时请求缓冲满 | 确定性丢弃，不 Fault | [6 · 符卡与整局编排](6-spell-and-stage.md) |
| 时停期间的相位跳过 | 冻 C 时相位 6/7/9 不跑 ⇒ 不判定、不结算、不回收（bomb 不冻 C，判定/结算/回收照跑，与时停不同） | spec §4 |

字节码层的完整口径（fault 码表、加载时代码校验、每个 syscall 的越界处置）见
[`ecl-ops.md`](../ecl-ops.md)。

## 已知限制（v1）

禁递归 · locals 静态分配（同 sub 内变量名不可重名）· sub 无返回值 ·
时间标签 `+N:` 未进 v1（显式 `wait`）。

<details><summary>已作废的一条限制：跨文件常量共享</summary>

曾列在这里的"**跨 `.ecl` 文件无共享的自定义常量机制**"**已作废**（2026-07-31 实测
否定）：多文件是"合并后单管线编译"，`const` 天然跨文件可见，见
[6 · 符卡与整局编排](6-spell-and-stage.md)「多文件」节。仍然没有的
只是**引擎侧的号段协调**——globals 自由段槽号、符卡 id 撞号不报错，靠作者自律。

</details>
